# Story 1.1: Chat UI with AI-powered query handling

## Status

Ready for Review

## Story

As a sourcing user,
I want to submit product queries via a chat interface and receive streamed responses powered by the AI layer,
so that I can quickly discover relevant product listings without complex forms.

## Acceptance Criteria

1. A chat UI allows entering a free-text product query and submits to a backend API route.
2. The backend uses the AI layer to process the query and stream responses back to the UI.
3. If product data is required, the AI layer signals the MCP layer to fetch live listings, and responses include structured product artifacts when available.
4. Responses render in the chat feed with basic formatting; product cards display in the artifact area when included.
5. For authenticated users, messages can be persisted; for guests, messages remain in session memory only. (Persistence can be stubbed for this story, but the interface must be ready.)
6. Error states are handled gracefully with user-friendly messages.

[Sources: prd.md#core-features, prd.md#user-experience, prd.md#technical-architecture, architecture.md#1.-system-components-&-technologies, architecture.md#2.-data-&-request-flow]

- Data Models
  - Chat (from PRD): id, userId, messages[], timestamp. No internal product tables; product data is transient from MCP. [Source: prd.md#data-models]

- API Specifications
  - Backend: Next.js API route handles AI request orchestration and returns streamed responses. [Source: architecture.md#backend]
  - AI Layer: Vercel AI SDK v4 streams responses; DeepSeek for MCP capabilities; Qwen for general chat. [Source: architecture.md#ai-layer]
  - MCP: Invoked by AI layer to fetch live product listings when needed. [Source: architecture.md#mcp-layer]

- Component Specifications
  - Chat UI is primary input surface; product cards appear alongside chat feed (not replacing it). [Source: prd.md#user-experience]
  - Minimalist design; contextual filters may appear later (not in this story scope). [Source: prd.md#ui-ux-considerations]

  - Chat UI lives under `app/(chat)/` with supporting components under `components/` (align with existing structure).
